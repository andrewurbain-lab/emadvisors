# EMA Advisors Website

A responsive, single-page website recreated from the supplied visual mockup.

## Publishing
Upload `index.html`, `styles.css`, `script.js`, and the `images` folder together to the root of your hosting repository.

## Forms
The consultation and candidate forms include Netlify form attributes. When hosted on Netlify, submissions can be collected without additional backend code. On GitHub Pages, connect the forms to Formspree, Basin, or another form endpoint before launch.
